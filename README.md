# compact-lib
A library with collections of reusable codes for Minecraft Paper API, written in Kotlin.

## Required Dependencies
- Kotlin 2.4.20 (or any recent Kotlin version)
- Paper API >=26.1
- Java 25

## Usage
### Gradle
```kotlin
dependencies {
    implementation("io.github.runkang10:compact-lib:VERSION")
}
```

### Maven
```js
<dependency>
    <groupId>io.github.runkang10</groupId>
    <artifactId>compact-lib</artifactId>
    <version>VERSION</version>
</dependency>
```
